# Contributing

[简体中文](./CONTRIBUTING.zh-CN.md) · [Back to the collection](./README.md)

Suggest a paper, share a tool or demo, or correct an existing entry through the [issue forms](https://github.com/jiangjin1999/awesome-multimodal-agentic-coding/issues/new/choose). English and Chinese submissions are equally welcome. You do not need to prepare both translations or choose the final category.

## Suggest a work

Please provide its official title, an original author or project link, and one sentence explaining what readers can learn from it. Include a paper, source repository, or demo when available.

For a feedback-driven system, a particularly useful detail is **what the agent observes after execution and how that changes its next code or tool action**. A paper section, figure, code location, or demo timestamp makes the example easier to understand. If this is unknown, say so; related foundations and practical resources are also welcome.

- **Core:** code or a programmatic representation produces an artifact; a post-execution multimodal observation changes a later code or tool action in the same trajectory. For a benchmark, identify the configuration that uses this loop.
- **Adjacent:** related generation, evaluation, or interaction work with a different feedback setup.
- **Resource:** a skill, tool bridge, engine, or attributed demo. Resources are listed in their own sections and are not counted as papers.

These are scope categories, not rankings. Inclusion is based on the work itself and is independent of whether its authors share or star this repository.

## Submit a pull request

Use the closest existing section and preserve the official title, original links, and first-publication date. Add a concise description of the mechanism and, for core papers, a line describing the verification dimensions. Avoid treating final evaluation as feedback received by the agent.

Keep the English and Chinese README entries aligned when possible; if you can contribute only one language, mention that in the PR and the maintainer can help with the translation. Reuse existing tags and avoid listing the same paper twice.

Small corrections are welcome. For a new category or a large reorganization, open an issue first so we can discuss the structure.
