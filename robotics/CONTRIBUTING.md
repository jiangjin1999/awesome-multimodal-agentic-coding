# Contributing

This repository is the robotics branch of [Awesome Multimodal Agentic Coding](https://github.com/jiangjin1999/awesome-multimodal-agentic-coding). Every file here is generated from upstream data and synced automatically, so changes made here would be overwritten.

To suggest a work, correct an entry or discuss scope, open an [issue](https://github.com/jiangjin1999/awesome-multimodal-agentic-coding/issues/new/choose) or a pull request upstream. The [contribution guide](https://github.com/jiangjin1999/awesome-multimodal-agentic-coding/blob/main/CONTRIBUTING.md) describes the entry format.

## 贡献

本仓库是 [Awesome Multimodal Agentic Coding](https://github.com/jiangjin1999/awesome-multimodal-agentic-coding) 的机器人分支。这里的所有文件都由上游数据生成并自动同步，直接在这里修改会被覆盖。

推荐论文、纠正条目或讨论收录范围，请在上游提交 [Issue](https://github.com/jiangjin1999/awesome-multimodal-agentic-coding/issues/new/choose) 或 PR，条目格式见[贡献指南](https://github.com/jiangjin1999/awesome-multimodal-agentic-coding/blob/main/CONTRIBUTING.zh-CN.md)。

## コントリビュート

このリポジトリは [Awesome Multimodal Agentic Coding](https://github.com/jiangjin1999/awesome-multimodal-agentic-coding) のロボティクス・ブランチです。ここにあるファイルはすべて上流のデータから生成されて自動で同期されるため、ここでの変更は上書きされます。

研究の推薦、項目の修正、収録範囲の議論は、上流で [Issue](https://github.com/jiangjin1999/awesome-multimodal-agentic-coding/issues/new/choose) またはプルリクエストを作成してください。項目の形式は[コントリビュートガイド](https://github.com/jiangjin1999/awesome-multimodal-agentic-coding/blob/main/CONTRIBUTING.ja.md)にあります。
